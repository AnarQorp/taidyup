# Security Policy

## Reporting Security Vulnerabilities

tAIdyup takes security and privacy very seriously. As a 100% local-first tool, tAIdyup runs without uploading source code or telemetry to external servers.

If you discover a security vulnerability or secret leakage risk in tAIdyup:

### Reporting Protocol
- **Do NOT create a public GitHub issue.**
- Email details of the vulnerability to: **`security@anarqorp.com`** (or open a confidential security advisory on GitHub).
- Include:
  - tAIdyup version (`taidyup --version`).
  - Environment details.
  - Steps to reproduce.
  - Potential impact.

### Response Timeline
- **Acknowledgement:** Within 24 hours.
- **Triage & Assessment:** Within 72 hours.
- **Patch Release:** Target within 7 days depending on severity.

Thank you for helping keep tAIdyup secure for all AI builders!
