# Onboarding V1 bundled demo

Controlled local evidence for first-use teaching. The bridge runs the real manifest parser, repository scan, n8n workflow adapter, runtime importer, and Trust Kernel reconciliation. It does not return precomputed state, start n8n, connect to a provider, or execute the workflow.

The workflow SEND declaration and observation use an exact typed resource descriptor. Runtime V0 deliberately records its separately bound safe resource identifier; therefore the runtime SEND occurrence remains an evidence-scoped undeclared observation rather than being falsely attached to the typed workflow resource.
